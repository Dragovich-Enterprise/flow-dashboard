Import older history (CSV)

Capital One only shares ~90 days through Plaid. Download older transactions as CSV from your bank's website, then import them here. Only rows older than the earliest synced transaction for that account are added, so nothing is double-counted.

Reset connections

Only needed if a bank connection breaks or you want a clean start. This disconnects your banks and clears pulled and imported transactions (budgets and goals are kept), then you link each bank again. Capital One still only returns ~90 days, so use the CSV import above for older history.
